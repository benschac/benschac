#### 🔍 Debugging in the open

**[PostHog × Sentry iOS launch failure](https://github.com/PostHog/posthog-js/issues/4285):** My iOS app built fine but never got past the splash screen. I traced the hang to the PostHog and Sentry Expo plugins interfering with each other, then posted a reproduction, the root cause, and a workaround. PostHog [shipped a fix](https://github.com/PostHog/posthog-js/pull/4291).
